## 一、结论：`3000 步接近上限`

**依据数字（三档判据逐条核对）：**

- 卡面「5000 步仍有收益」要求「val 最低点后移且收益 ≥0.05」——**不满足**：本轮 5000 步 val 最低点仍在**步 2100**（2.67325），与 3000 步基线的最低点步号（2100）**相同，没有后移**；从步 3000（2.71068）续训到 5000（2.91890）的收益是 **−0.20822**（越训越差，绝非 ≥0.05）。
- 卡面「3000 步接近上限」要求「5000 步 val 收益 <0.02 且已回抬」——**满足**：续训收益 −0.20822 < 0.02；val 从最低点 2.67325（步 2100）回抬到末值 2.91890，相对回抬 **+9.19%**；脚本判定 `overfit_step=2600`（val 相对历史最优回升 >1% 的首个步）；4500—5000 区间单调上行（2.87849→2.91890，+0.04041），末值比 3000 步基线末值（2.71567）还高 **+0.20323**。
- 因此判 `3000 步接近上限`，不判 inconclusive（差异远大于噪声，见 §五）。

**一句话**：同一配置、seed、数据、机器跑到 5000 步，val 在步 2100 触底后不但没有继续下降，反而从步 2600 起持续回抬，5000 步末值显著劣于 3000 步——**3000 步对该 3.4M 模型+1.47M token 数据已是上限附近，继续加步数有害无益**；按报告 §九-1 的思路，要继续涨点应优先加真实数据而非加步数。

### 2.3 必须登记的口径差异（confound，不掩盖）

训练脚本 `train_demo.py` **没有 `--resume` 参数**，cosine LR 的 warmup 与总步数绑定（自动取 `max(3, steps//50)`：3000 步档 warmup=60，5000 步档 warmup=100），整条 LR 曲线也随总步数缩放。因此本卡按卡面指定的唯一可复现路径——「同配置/同 seed/同数据**从零跑满 `--steps 5000`**」——执行，**不是**从 3000 步 checkpoint 续跑（代码不支持，硬续需改训练脚本，违反"验收卡不改代码"）。

对照影响：在相同步号上两档 LR 不同（例如步 2100：3000 档 8.78e-5、5000 档 2.03e-4；步 3000：3.0e-5 vs 1.27e-4），5000 步档在 2100—3000 段 LR 更高、理论上更利于继续下降，但实测 val 仍回抬——这反而使「5000 步无收益」的结论更强（若续跑还给了额外优势仍无收益）。跨 run 的全程最优对比（2.69325 vs 2.67325，差 0.02）受此混杂，故结论主要依据同 run 内的 3000→5000 段与回抬判据，不单靠跨 run 最优差。

### 2.4 耗时与机器负载（诚实登记）

### 4.3 结构合法率对比的解读

产品列两 checkpoint 都是 1.0（状态机强制，无区分力）；能力结构率两者都是 0.4；真正的能力列代码段合法率 5000 步（0.40）**略低于** 3000 步（0.45）。这与 val 曲线的回抬方向一致——5000 步不仅没有带来生成质量收益，也没有超过 3000 步，进一步支持「3000 步接近上限」。

## 五、噪声估计与证据等级

- **噪声估计方式**：取 3000 步基线**平台段**（步 ≥2100 至 3000，10 个 eval 点）val loss 的总体标准差 **σ=0.00850**（约 0.31% 相对）；5000 步运行 2100—2500 近平台段 σ=0.00360，量级一致。不使用 5000 步后段做噪声——那里是真实的过拟合漂移（信号，不是噪声），会把 σ 撑大造成「差异落在噪声内」的误判。
- 5000 步相对 3000 步的末值差 +0.20323 是 σ 的 **24 倍**；4500—5000 单调回抬 +0.04041 是 σ 的 **4.8 倍**；均远超噪声，故不判 inconclusive。
- **证据等级**：val 曲线（最低点、回抬、overfit_step、噪声）为直接测量、强证据；checkpoint 结构合法率为固定 20 条集真实生成+真实 checker、强证据；跨 run 全程最优差（0.02）受 LR 曲线差异混杂、仅作旁证（中），结论不依赖它。
